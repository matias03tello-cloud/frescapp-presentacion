03 · Persistencia

Firebase / Cloud Firestore

Inventario por cuenta

Guarda los registros personales en la nube. El acceso aislado por usuario debe comprobarse con reglas de seguridad y pruebas.

Flujo previsto: usuario → formulario móvil → validación local y búsqueda en dataset → guardado del producto y su fecha en Firestore → consulta y priorización en la app. El catálogo de productos y el inventario personal son datos distintos. No se afirma que el control de acceso esté validado hasta probar las reglas de Firebase.

Por qué esta combinación

React Native + Expo permite reutilizar gran parte del código entre Android e iOS y acelerar el prototipo.

Alternativa considerada: desarrollo nativo

Ofrece integración directa con cada plataforma, pero normalmente exige mantener implementaciones separadas. Para un proyecto académico, Expo reduce el esfuerzo inicial; la compatibilidad de módulos y el rendimiento deben probarse.
