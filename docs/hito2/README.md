# FrescApp — materiales del Hito 2

## Backend y colección de pruebas

El código fuente está en [`matias03tello-cloud/arq-app-compras`](https://github.com/matias03tello-cloud/arq-app-compras). Allí están la API REST, sus capas y validadores, el modelo Firestore, el informe técnico y el PDF.

- [Informe técnico del backend](https://github.com/matias03tello-cloud/arq-app-compras/blob/main/docs/hito2/BACKEND_HITO2.md)
- [Informe técnico en PDF](https://github.com/matias03tello-cloud/arq-app-compras/blob/main/docs/hito2/FrescApp-Backend-Hito2.pdf)
- [Modelo de datos Firestore](https://github.com/matias03tello-cloud/arq-app-compras/blob/main/db/MODELO_HITO2.md)
- [Mapa de responsabilidades de la API](https://github.com/matias03tello-cloud/arq-app-compras/blob/main/functions/api/README.md)
- [Colección Postman para emuladores locales](https://github.com/matias03tello-cloud/arq-app-compras/blob/main/docs/hito2/FrescApp-Hito2.postman_collection.json)

La colección usa Firebase Emulator Suite en `127.0.0.1`; no llama APIs externas ni servicios de producción. Impórtala como archivo local y mantenla en el workspace local de Postman.
