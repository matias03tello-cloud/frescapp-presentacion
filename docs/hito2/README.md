La colección y las instrucciones usan Firebase Emulator Suite en `127.0.0.1`; no apuntan a un backend público ni incluyen tokens. En Postman, importar el JSON como archivo local y mantener la colección en el workspace local.

Este repositorio de GitHub sirve las presentaciones y materiales de apoyo. La carpeta del código de FrescApp sigue siendo la fuente del backend; al momento de la revisión local no tenía remoto Git configurado.
